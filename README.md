# 🚀 Space Exploration Quiz

A 10-question space quiz in a single `index.html` — no server, build, or dependencies.

- Progress bar and live score counter
- Animated feedback: green pop for correct, red shake for wrong
- Emoji reaction on the results screen
- Light/dark theme via `prefers-color-scheme`
- Keyboard friendly: press 1–4 to answer

## Run
Open `index.html` in any modern browser.
